## Changed behavior

- An owned client's default dashboard now opens a bilingual outcome home with persisted site health/pillars, scan history, observed Pulse visibility and permitted generated recommendations. Explicit scan/results/improve/monitor/roi links and selected-scan ownership remain intact.
- The home and overview API share an account/client-bound, read-only loader. Missing ownership remains distinct from a query failure; home panels may fail independently, while overview retains 401/404/500 rather than returning partial failure as successful empty data.
- Pulse selects the newest available week across summaries and raw observations, including histories longer than 40 weeks. A missing aggregate, absent usable denominator, whitespace-only answers or inconsistent persisted numerator/denominator yields unavailable. This is evidence of matching stored observations, not proof that every provider completed or that fallback analysis was semantically successful. Freshness stays unknown; no stale threshold is invented.
- Existing commercial entitlements now filter home/API agent fields at the server boundary. The direct legacy Improve step also omits denied agent queries/data and filters recommendation platforms before client serialization. Progress/competitor platform vocabularies keep their established feature-only permissions. The separate existing ROI competitor input remains scoped to that step and its entitlement.
- Notification query failures show unknown rather than zero. List reads and mark-all-read failures stay visible and retryable; failed writes preserve unread state, and a pending read blocks marking. A bounded latest-20 list never establishes the global count: successful unknown-state reads refresh the authoritative server count.
- Mobile navigation has a visible toggle, bounded scrolling and 44px controls. Home supports English/zh-HK, light/dark and narrow/wide layouts.
