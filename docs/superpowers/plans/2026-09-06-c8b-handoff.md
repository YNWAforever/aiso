## Changed behavior

- The authenticated portfolio shows active owned brands, with explicit observed Pulse week, unavailable/error states and unknown freshness. A newer raw-only week cannot silently fall back to an older summary.
- A new tenant-scoped loader performs four batched reads for populated portfolios: authoritative active brands, all-owned brand count, latest ten owned scans and per-client latest Pulse evidence. It does not fetch full workspaces or agent arrays for every brand. Empty portfolios omit the unnecessary Pulse query.
- Pulse projection is shared with C8a through a pure extraction with unchanged semantics. Per-client latest weeks, usable denominators and matching persisted mention counts remain separate; a genuine observed zero may display 0%, while missing evidence does not.
- Creation availability uses the count of all owned brands, including inactive ones, matching the existing creation API/trigger. An unavailable count shows a distinct message and no creation control. A known full allowance shows the actual count/limit and pricing link. Capacity remains advisory: the existing API and database trigger independently enforce entitlement and concurrency rules.
- Recent history retains stored scores/grades and both established guarded result-link forms. English/zh-HK dates use explicit UTC formatting; invalid/missing dates remain unavailable. No fabricated grade, improvement delta, ranking or comparable-performance claim was added.
- Authoritative client lookup failures render a localized load error. Optional history, Pulse and count failures remain distinguishable from empty data. The DTO excludes account fields and raw answer text.
